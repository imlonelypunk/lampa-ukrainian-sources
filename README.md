# Українські джерела для Lampa

Один плагін із меню UASerials, UAKino й Teleportal та спільним пошуком.
Працює через звичайні запити Lampa до сайтів і відкриває знайдені відеопотоки
у вибраному плеєрі Lampa. Окремого сервера для пошуку чи відео немає.

Адреса встановлення та оновлень:

**https://imlonelypunk.github.io/lampa-ukrainian-sources/ua.js**

У Lampa: **Налаштування → Розширення → Додати плагін** → ця адреса →
**Встановити**. Для вже встановленої тестової копії відкрийте її дії →
**Змінити адресу** й замініть `http://127.0.0.1:8768/ua.js` на HTTPS-адресу вище.
Після цього перезапустіть Lampa.

Відкрити плагін: на головному екрані натисніть **←**, прокрутіть ліве меню
вниз після **Shots**, оберіть **Українські джерела** й натисніть **OK**.
Далі оберіть **UASerials**, **Teleportal** або **Пошук у трьох джерелах**.

Зібраний файл: `dist/ukrainian-sources.js` (ідентичний `dist/ua.js`).
Публікація GitHub Pages використовує тільки каталог `docs/`; це окремий
репозиторій плагіна.

Версія 0.1.2 виправляє прокручування довгих списків із пульта: вибраний рядок
залишається у видимій частині екрана. Для отримання оновлення перезапустіть Lampa;
адреса плагіна залишається тією самою.

У UASerials/UAKino відкрийте каталог або пошук → матеріал → плеєр/озвучення →
серію. Для Teleportal спочатку введіть назву шоу чи серіалу українською.
Список серій передається плеєру Lampa як плейлист. Для окремих випусків сайт
може не повернути відео; це відображається повідомленням.

На цій прошивці служба трансляції створює віртуальні екрани, які VLC може
помилково вибрати для відео. На цьому HY300PRO у VLC увімкнено
**«Переважно клонувати»**. Телевізійний інтерфейс VLC залишено ввімкненим.
Якщо після скидання налаштувань знову видно помаранчевий значок трансляції,
відкрийте панель керування VLC та натисніть значок екрана вгорі праворуч.

Опція клонування прихована в інтерфейсі ТВ. Для зміни потрібна мишка:
**Інше → Параметри → Інтерфейс → Інтерфейс ТБ Андроїд** — тимчасово вимкнути,
підтвердити жестом і перезапустити VLC. У мобільному інтерфейсі:
**Більше → Параметри → Відео → Додатковий дисплей → Переважно клонувати**.
Після цього знову ввімкніть **Інтерфейс ТБ Андроїд** у розділі **Інтерфейс**
і перезапустіть VLC. Для відкату зніміть прапорець **«Переважно клонувати»**.
Служби трансляції проєктора для цього вимикати не потрібно.

Для Teleportal на перевіреному HY300PRO довелося вимкнути апаратне прискорення
саме у VLC: **Інше → Параметри → Апаратне прискорення → Вимкнено**.
Попередній режим — **Автоматично**; повернення тим самим шляхом.
Зміна стосується VLC, параметри проєкції та прошивка не змінюються.
У **Параметри → Відео → Бажана роздільна здатність** також встановлено
**HD (720p)** замість **Найкраща доступна**: тестовий адаптивний потік
переходив у 1080p із тривалим буферизуванням. Параметр діє для потоків,
які підтримують вибір якості; повернути попереднє значення можна тут само.

## Межі підтримки

- UASerials: HTML-каталог, iframe та звичайні JSON/Playerjs-плейлисти.
- UAKino: HTML-каталог, публічні AJAX-плейлисти й підтримувані iframe.
  Станом на перевірку 2026-11-01 сайт повертав HTTP 403 і з ПК, і з проєктора.
- Teleportal: публічний пошук, сезони, випуски та офіційний HLS-потік.
- Обфусковані скрипти, DRM, авторизація й перевірки CAPTCHA не обходяться.
  Завантажений JavaScript із сайтів не виконується.
- Сайт може змінити розмітку чи доступність. У такому разі плагін показує
  помилку й дозволяє повторити запит. У браузері можуть діяти обмеження CORS;
  цільова платформа цієї збірки — Lampa Android з нативними запитами.

## Локальна розробка

Потрібен Node.js. Залежності використовуються лише для тестування.

```powershell
npm ci --ignore-scripts
npm test
npm run build
python -m http.server 8768 --bind 127.0.0.1 --directory dist
```

Для тимчасової установки з комп'ютера через ADB:

```powershell
adb -s IP:PORT reverse tcp:8768 tcp:8768
```

Адреса на проєкторі: `http://127.0.0.1:8768/ua.js`.
Це тестова адреса: ADB-перенаправлення зникає після перезапуску пристрою.
Lampa кешує код плагіна, але кеш не заміняє постійну адресу для оновлень
і може бути втрачений при очищенні даних. Для розповсюдження розмістіть
готовий JS-файл на своєму статичному HTTPS-хостингу.

Під час першої тестової установки перевірено холодний запуск Lampa після зупинки сервера
й видалення ADB-перенаправлення: меню версії 0.1.1 відкрилося з кешу.
У списку розширень локальна адреса тоді позначається як недоступна/404,
і Lampa може показати повідомлення про незавантажений плагін. Це стосується
перевірки адреси; збережена копія продовжує працювати. Для звичайного
використання потрібна постійна HTTPS-адреса, вказана вище. Не покладайтеся
на кеш як на резервну копію: збережіть JS-файл або архів джерел.

Публікація оновлень: `npm run build`, перевірити тести, закомітити зміни
та завантажити їх у `main`. GitHub Pages налаштовано на `main` → `/docs`.
Адреса `ua.js` залишається сталою. Локальні журнали `.live/`, залежності
та дані проєктора до репозиторію й публікації не входять.

Видалення: у **Розширеннях** відкрийте дії цього плагіна → видалити,
потім перезапустіть Lampa. Кеш/дані всієї Lampa очищати не потрібно.
