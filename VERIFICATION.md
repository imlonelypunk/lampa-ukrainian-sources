# Перевірка 2026-11-01

Ціль: Magcubic HY300PRO, Android 14, Lampa Android 1.13.5.

## Підтверджено

- `npm test`: 28 перевірок, усі пройдені. Покрито розбір каталогів і
  вкладених списків озвучень/серій, відповіді Teleportal, некоректні формати,
  тайм-аут, скасування, незалежні результати пошуку, керування рядками,
  відсутність повторної обробки OK при віртуальному фокусі Lampa.
- `npm run build` і `node --check dist/ua.js`: успішно.
- Установлення на проєктор: Lampa завантажила `http://127.0.0.1:8768/ua.js`
  через ADB reverse; позначила HTTP 200 і закешувала код. Меню трьох джерел
  відкрилося. Каталог UASerials з обкладинками відображений на пристрої.
  Пультом відкрито картку, вкладений плеєр і список із 8 серій з озвученням
  Bezro Studio. Перша серія передана до VLC через налаштування Lampa.
- UASerials із ПК: 30 карток каталогу, 18 результатів пробного пошуку,
  вкладений плеєр з 8 серіями; URL першої серії повернув HLS `#EXTM3U`.
- Teleportal із ПК: справжні результати пошуку, 40 пунктів вибраного проєкту,
  старіший випуск повернув офіційний HLS `#EXTM3U`.
- Тимчасовий HTTPS-пробник без вимкнення перевірки сертифікатів на
  проєкторі: UASerials 200, Teleportal API 200, UAKino 403.
  Пробник прибраний з пристрою після запуску.

## Обмеження

- UAKino повернув HTTP 403 і з комп'ютера, і з проєктора. Його каталог
  та відтворення в поточній мережі не підтверджені. Захист сайту не обходився.
- Перший перевірений рекламний HLS Teleportal завершився HTTP 504 на сервері
  сегмента; основним у плагіні став інший готовий URL, який повернув API.
- Найновіший перевірений випуск Teleportal повернув порожні поля медіа,
  хоча каталог доступний. Відсутність відео показується як помилка.
- Відео першої серії UASerials відтворилося на проєкторі у VLC. Для цього
  вимкнено вторинний вихід відео VLC: прошивка створює віртуальні екрани
  служби Toofifi, які VLC сприймав як зовнішній дисплей.
  Відео Teleportal також відтворилося: пошук «холостяк» → сезон 14 → випуск 6
  → основний потік → VLC. На цій прошивці апаратний MediaCodec зависав;
  режим VLC «Апаратне прискорення» змінено з «Автоматично» на «Вимкнено».
  Програмний декодер avcodec і кадр відео підтверджені журналом/знімком.
  Власник підтвердив звук серіалу UASerials. Звук Teleportal і довге
  відтворення ще не підтверджені.
  Холодний запуск кешу перевірено: сервер ПК зупинений, ADB reverse відсутній
  на обох з'єднаннях, Lampa примусово закрита й запущена заново; після цього
  пункт «Українські джерела» і меню версії 0.1.1 відкрилися.
  Знімки: `.live/cache-menu-focus.png`, `.live/cache-home-pass.png`.
- Під час початкової перевірки загальнодоступного URL для оновлень ще не було.
  Адреса через ADB призначена для локальної установки. Без сервера Lampa
  показує недоступність цієї адреси, потім використовує кеш. Очищення даних
  програми може вимагати повторної установки з резервного JS-файлу.
  Постійна адреса GitHub Pages наведена в поточному `README.md`.

Локальні журнали/кадри: `.live/`; вони не входять до дистрибутива.
Хеші збірки й окремих JS-файлів: `dist/build.json`.

## Повторна перевірка виводу VLC

Власник повідомив про значок VLC зі звуком; на поточному екрані підтверджено
повторний вибір віртуального дисплея. Через видимі налаштування VLC 3.7.2
тимчасово вимкнено інтерфейс ТВ, у мобільному меню ввімкнено **«Переважно
клонувати»** (початково вимкнено), потім інтерфейс ТВ увімкнено назад.
Після примусового закриття та нового запуску VLC перевірено новий VIEW-запуск
тієї самої серії: зображення з'явилося на основному екрані без натискання
перемикача дисплея. Знімок: `.live/clone-fresh-after-wait.png`.
Журнал зміни/відкату: `.live/vlc-clone-action.json`.
Служби Toofifi та інші засоби трансляції не змінювалися.

Повторно пройдено шлях у Lampa: меню джерел → UASerials → «Кульгаві коні»
→ плеєр → перша серія → VLC. Відео на основному екрані підтверджено без
ручного перемикання дисплея (`.live/clone-lampa-video-confirm.png`). Водночас
автоматична якість перейшла з 854×426 у 1920×960; журнал містить тривале
буферизування та запізнілі кадри. Цей негативний результат збережено у
`.live/clone-lampa-output-log.txt`. Тому бажану роздільність VLC змінено
з **Найкраща доступна** на **HD (720p)**; це окремий параметр від декодера.
Перша спроба після цієї зміни завершилася тайм-аутом TLS медіасервера;
журнал збережено у `.live/clone-720-system-log.txt`. Після одного повтору
відео з'явилося на основному екрані, а декодер перейшов із 854×426 у
1280×640 (широкоформатний варіант 720p), не у 1920×960.
Докази: `.live/clone-lampa-720-retry.png`, `.live/clone-720-retry-log.txt`.
Це коротка перевірка запуску; стабільність тривалого перегляду не встановлена.
